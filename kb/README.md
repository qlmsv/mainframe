# База знаний

Отсюда диспетчер берёт ответы, когда отвечает людям за тебя. Он ищет по файлам (Grep) и читает их (Read), поэтому:

- пиши обычным текстом в markdown, один файл на тему;
- держи факты точными: цены, ссылки, даты, условия;
- если ответа здесь нет, диспетчер не выдумывает, а спрашивает тебя.

Папку можно поменять в `.env` (`KB_DIR`). Например, `KB_DIR=~/Assistant`, чтобы искать по всем твоим заметкам.
