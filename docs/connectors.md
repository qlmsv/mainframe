# Почта и Google с любой моделью

Коннекторы claude.ai (Gmail, Календарь, Drive) работают только с подпиской Claude. Эти работают с любой моделью (DeepSeek, GLM, Kimi, Qwen и др.) и в любом режиме. Пароли и ключи хранятся только на твоём сервере (в `.env` и `data/google`), в чат их не присылай.

## Почта (IMAP и SMTP)
Мастер настройки (шаг «Почта и Google») или пульт: Ещё → Система → Почта. Нужны адрес и **пароль приложения** (не обычный пароль):

| Почта | Где взять пароль приложения |
|---|---|
| Gmail | myaccount.google.com/apppasswords (нужна двухэтапная проверка) |
| Яндекс | id.yandex.ru → Безопасность → Пароли приложений → Почта |
| Mail.ru | id.mail.ru → Безопасность → Пароли для внешних приложений |
| iCloud | account.apple.com → Вход и безопасность → Пароли приложений |
| Своя почта на домене | серверы IMAP и SMTP даёт хостинг почты |

Что умеет помощник: искать и читать письма, присылать новые во «Входящие», отвечать на них кнопкой из «Входящих». **Новое письмо уходит только после твоей кнопки «Отправить» в боте**: это проверяется в коде, модель отправить письмо сама не может.

## Google Календарь, Диск, Документы, Таблицы
Через открытый сервер [workspace-mcp](https://github.com/taylorwilsdon/google_workspace_mcp) (MIT). Нужен свой клиент Google, это бесплатно, около 5 минут:

1. [console.cloud.google.com](https://console.cloud.google.com/projectcreate): создай проект.
2. Включи API: Google Calendar, Google Drive, Google Docs, Google Sheets (кнопка «Enable»).
3. «Google Auth Platform» → Branding: имя приложения, твоя почта. Audience: тип «External», потом **«Publish app»**. Без публикации вход слетает через 7 дней.
4. Clients → Create client → тип **«Desktop app»**. Скопируй Client ID и Client secret в мастер или пульт.
5. «Войти в Google» → выбери аккаунт. Google предупредит, что приложение не проверено: «Дополнительные настройки» → «Перейти». Это твоё собственное приложение.
6. Откроется пустая страница с ошибкой, это нормально. Скопируй её адрес (`http://127.0.0.1:8085/?…code=…`) и вставь в поле «Готово».

Gmail через вход Google тоже можно (вместо пароля приложения), но проще пароль приложения.
