# Где работает помощник: три режима

| | Только сервер | Только компьютер | Сервер + компьютер |
|---|---|---|---|
| Работает круглые сутки | да | пока компьютер включён | да |
| Бот, память, расписание | да | да | да |
| Браузер | на сервере, без твоих входов | твой Chrome со входами | Chrome компьютера, когда он выключен, браузер сервера |
| Почта и Google | по паролю приложения и входу Google | то же, на Mac ещё Почта, Календарь, Заметки | то же |
| Управление программами компьютера | нет | да | когда компьютер включён |
| Голосовые | на сервере | на компьютере | на сервере или компьютере |
| Что нужно | сервер от 2 ГБ | Mac или Windows 10/11 | сервер и Mac или Windows |

Режим выбирается первым шагом в мастере настройки, поменять можно в пульте: Ещё → Система → Где работает.

## Только сервер
Установка как в [install-student.md](install-student.md). На сервер сами ставятся Claude Code (официальный установщик, команда `claude`), браузер без экрана (Chromium и chrome-devtools-mcp) и сервер для Google. Почту и Google подключи в мастере или пульте: [connectors.md](connectors.md).

## Только компьютер
Сервер не нужен. Помощник работает, пока компьютер включён и не спит.

**Mac** (программа «Терминал»):
```
curl -fsSL https://raw.githubusercontent.com/qlmsv/mainframe/main/scripts/install-computer.sh | bash
```
**Windows 10/11** (PowerShell, обычный, не от администратора):
```
irm https://raw.githubusercontent.com/qlmsv/mainframe/main/scripts/install-windows.ps1 | iex
```
В конце сам откроется мастер настройки `http://127.0.0.1:7777/setup`. Автозапуск при входе: на Mac launchd, на Windows «Планировщик заданий».

На Windows Claude Code входит не по ссылке: открой PowerShell, выполни `claude setup-token` и вставь токен в мастер (поле «Уже есть токен Claude?»). Или выбери другую модель по ключу.

## Сервер + компьютер
Сначала сервер (как «Только сервер», в мастере выбери «Сервер + компьютер»). В конце мастер, а потом и пульт (Ещё → Система → Компьютер → «Подключить компьютер») дают команду с одноразовым кодом. Код действует час и один раз.

- **Mac**: команду в «Терминал». Подключит браузер (отдельный профиль Chrome), управление Mac, Почту, Календарь, Заметки, Напоминания, голосовые по желанию и задачи с кодом на Mac, если включён «Удалённый вход».
- **Windows**: команду в PowerShell, по шагам: [install-windows.md](install-windows.md). Подключит управление Windows (Windows-MCP), браузер (отдельный профиль Chrome), голосовые по желанию.

Пароль от сервера не нужен. Компьютер сам открывает туннель к серверу, снаружи на компьютере ничего не слушает. Сервер пускает ключ компьютера только на порты моста.

## Из России
Все три режима работают. Российский сервер и что делать, если Telegram с него не открывается (MAX вместо Telegram): [install-ru.md](install-ru.md). В режиме «Только компьютер» бот ходит в Telegram с твоего компьютера: если Telegram у тебя открывается только через VPN, помощнику тоже нужен VPN. Почта Яндекс и Mail.ru подключаются по паролю приложения. Google из России может не открываться без VPN: календарь тогда лучше вести в Яндексе (подключится позже) или на Mac через Календарь.

## Обновление
Сервер: `bash ~/mainframe/scripts/update.sh` (код, Claude Code, браузер, коннекторы, перезапуск).
