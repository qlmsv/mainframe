# Мейнфрейм

Личный ИИ-агент, который работает на тебя круглосуточно. Живёт на твоём сервере, работает на твоей подписке Claude, управляется из Telegram-бота и веб-пульта.

## Что он делает

- **Входящие.** Читает твой Telegram, рабочие группы, почту и комментарии в канале. Неважное откладывает, важное приносит карточкой с готовым черновиком ответа. Отправляет только после твоего «да». Правила словами: «GitHub показывай тихо, кроме упоминаний меня», «от Ани пакетом раз в час». Срочное приходит сразу, остальное без звука.
- **Задачи голосом и текстом.** Пишешь или говоришь боту, он делает: в терминале, в коде, в файлах, в календаре, в почте. Сессии Claude Code по каждому проекту продолжаются с того же места.
- **Сводки.** Утром и вечером: встречи, напоминания, кто ждёт ответа, траты за день, что вышло в соцсетях.
- **Соцсети.** Студия постов в твоём стиле под Telegram, LinkedIn, Instagram, Threads, TikTok. Календарь, банк идей, слежка за конкурентами и черновики по их удачным постам, разбор твоих постов.
- **Финансы.** Траты из писем любого банка (письмо разбирает модель), чеки фото, остатки по скриншотам, итог в основной валюте из настроек.
- **Свои модули.** Всё, что нужно только тебе (свой банк, своя CRM, мессенджер, трейдинг), подключается папкой в `personal/`: она не попадает в git, а пульт и бот подхватывают её вкладки, команды и инструменты. Как устроен модуль: `src/modules.js`.
- **Память.** Помнит тебя, твои правила, людей и решения во всех разговорах. Поиск по всей истории: «что Аня писала про договор», «что решили про цену в октябре». Новое из разговоров дня приходит тебе на одобрение.
- **Расписание.** Любые задачи по cron, итог приходит в бот.

## Как устроен

```
              Telegram-бот и веб-пульт (https)
                          │
   ┌──────────── сервер, работает всегда ────────────┐
   │ шлюз на Node · SQLite · очередь · расписание    │
   │ сессии Claude (Agent SDK) · память · поиск      │
   │ твой Telegram-аккаунт · соцсети · финансы       │
   └───────────────▲─────────────────────────────────┘
                   │ SSH-туннель (его открывает Mac)
   ┌───────────────┴─── твой Mac, когда включён ─────┐
   │ Почта, Календарь, Заметки, Напоминания          │
   │ управление Mac · свой Chrome агента · голосовые │
   │ сессии по проектам, чьи файлы лежат на Mac      │
   └─────────────────────────────────────────────────┘
```

Пока Mac выключен, всё остальное работает, а задачи для Mac ждут его и запускаются сами.

## Что понадобится

1. **Подписка Claude Pro или Max.** Мейнфрейм работает на ней, ключ API не нужен.
2. **Сервер** с Ubuntu 22.04 или 24.04, от 2 ГБ памяти. Подойдут AWS (бесплатный план на 6 месяцев), Hetzner (около 4 € в месяц), DigitalOcean, Vultr. Российские хостинги не подойдут: Claude недоступен с российских адресов.
3. **Telegram-бот** от @BotFather (бесплатно, 1 минута).
4. **Mac** по желанию: для почты, календаря, голосовых и проектов с кодом.

## Установка

**Сервер.** Подключись к нему по SSH и выполни:

```bash
curl -fsSL https://github.com/qlmsv/mainframe/raw/main/scripts/install-server.sh | bash
```

Установщик спросит часовой пояс, имя, токен бота, проведёт через вход в Claude и Telegram-аккаунт (по QR-коду). В конце покажет код привязки бота и личную ссылку на пульт. Если у сервера облачный файрвол (на AWS это Security Group), открой в нём порты 80 и 443.

**Mac.** В Терминале на Mac:

```bash
bash <(curl -fsSL https://github.com/qlmsv/mainframe/raw/main/scripts/install-mac.sh) ubuntu@IP_СЕРВЕРА ~/путь/к/ключу.pem
```

Скрипт поставит мост, попросит разрешения macOS и включить «Удалённый вход», сделает токен Claude для сессий на Mac и по желанию соберёт расшифровку голосовых.

**Первые шаги.**
1. Отправь боту `/start КОД` из конца установки.
2. Расскажи о себе: «запомни, что я…», «запомни, что пишу без длинных тире». Это ляжет в память, и агент будет это учитывать везде.
3. Заполни базу знаний для ответов людям: папка `kb`, пример в `kb/примеры`.
4. Во вкладке «Соцсети» поставь цель и подбери конкурентов. Каждые 2 недели смотри «Разбор постов».

## Настройки

Всё личное хранится в `.env` и в папке памяти, не в коде. Главное:

| Переменная | Что это |
|---|---|
| `OWNER_NAME` | как тебя зовут |
| `SOCIAL_TG_CHANNEL` | твой канал без @ |
| `OFFER_URL`, `OFFER_CTA` | куда ведут посты и как это назвать |
| `CURRENCY` | основная валюта для итогов в «Финансах», например RUB, USD, EUR |
| `OWNER_TZ` | твой часовой пояс, например Europe/Moscow (иначе берётся пояс сервера) |
| `PERMISSION_MODE` | права агента, по умолчанию полные |
| `AUTO_FORWARD`, `AUTO_REPLY` | авто-режим для входящих (по умолчанию выключен) |

Полный список с пояснениями в `.env.example`.

## Безопасность

- Всё работает на твоём сервере и твоей подписке. Данные никуда не уходят, кроме самих сервисов, которые ты подключил (Claude, Telegram, коннекторы claude.ai).
- Вход на сервер только по ключу, файрвол, защита от подбора паролей, https.
- Пульт открывается только тобой: через бота или по личной ссылке с токеном.
- Сообщения людям, публикации, письма и удаление уходят только после твоего подтверждения.
- Каждую ночь в 03:30 резервная копия базы и памяти, хранится 14 дней, копия уходит на Mac.

## Обслуживание

| Что | Команда на сервере |
|---|---|
| Статус | `systemctl status mainframe` |
| Перезапуск | `sudo systemctl restart mainframe` |
| Журнал | `tail -f ~/mainframe/data/logs/mainframe.log` |
| Обновление | `cd ~/mainframe && git pull && npm ci --omit=dev && sudo systemctl restart mainframe` |
| Новый вход в Claude | `claude auth login` |
